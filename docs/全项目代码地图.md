### 单 Agent 与多 Agent 的分界

```
单 Agent（ChatAgent）
  一个模型 + 14 个工具，自己决定调哪个 → 适合"一问一答能解决"

多 Agent（Planner → Orchestrator）
  Planner 先出 WorkflowSpec（几个任务、谁依赖谁）
  → Orchestrator 按拓扑并行执行
  → Observer 校验质量，不够就重规划
  → Synthesis 综合成一段话
  适合"要多个专业视角拼起来"的复杂问题
```

## 注释是怎么验证的

每个文件改完都做 **AST 逐部件比对**：把新旧文件解析成语法树，去掉 docstring 后逐节点比较。
这样能发现任何逻辑改动 —— 包括签名相同但少一个 `.strip()` 这种肉眼看不出的问题。

```bash
# 提取备份
tar -xzf .workbuddy-ai/backups/app-20261022-172635.tar.gz -C /tmp/orig backend/app

# 比对（示例）
python3 - <<'EOF'
import ast
def strip_ds(t):
    for n in ast.walk(t):
        if isinstance(n, (ast.Module, ast.ClassDef, ast.FunctionDef, ast.AsyncFunctionDef)):
            if n.body and isinstance(n.body[0], ast.Expr) and isinstance(n.body[0].value, ast.Constant):
                n.body = n.body[1:] or [ast.Pass()]
    return t
a = ast.dump(strip_ds(ast.parse(open("/tmp/orig/backend/app/xxx.py").read())), include_attributes=False)
b = ast.dump(strip_ds(ast.parse(open("backend/app/xxx.py").read())), include_attributes=False)
print("✅ 一致" if a == b else "❌ 有逻辑改动")
EOF
```

全程验证结果：**96 个文件 AST 全部一致，209 个测试始终通过**。
